### 1280×720 での実表示の確認(R-1 / V-8)

puppeteer(viewport 1280×720、print メディア = `npm run pdf` と同条件)で `dist/index.html` を開き、#2 の `<img>` の表示サイズを `getBoundingClientRect()` で実測した。

- 図の表示サイズ: **幅 1050px × 高さ 252px**(computed `max-height: 252px`)
- 表示倍率: 1050 ÷ 1050 = **1.0**
- 最小の文字の実効サイズ: 18px × 1.0 = **18px**(地名・日付は 22px)。すべて 16px 以上
- スクリーンショットで、地名・手段・所要時間・泊数がすべて判読できることを目視で確認した

### 見出しの折り返し確認

同じ条件で、全スライドの h1(タイトル・目次・扉・本文見出し)とタイトルスライドのサブタイトルの行数を `Range.getClientRects()` で数えた。**すべて1行で、折り返しはない**(サブタイトルは高さ 31px の1行)。文言の追加変更はしていない。

- 参考: #2 の出典行(`<small>`)は「(2026年10月取得)」だけが2行目に折り返す。見出しではなく注記なので、そのままにした(はみ出しはない)。
