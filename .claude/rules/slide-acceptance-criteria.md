# スライドの固定合格基準

すべてのランで共通に適用する基準。検証エージェントはこの表の**全項目**について
判定結果と根拠を検証レポートに記載する。ID は検証レポートや
`npm run check -- <name>`(`scripts/check-slides.js`)の出力で参照する。

- **必須**: 1件でも不合格ならランは不合格
- **推奨**: 不合格でも全体は合格にできるが、理由をレポートに残す
- 判定方法 **自動** は `npm run build -- <name> && npm run check -- <name>` の結果で判定する
  (error = 不合格)。**目視** は検証エージェントがソースと成果物を読んで判定する。

## A. アクセシビリティ(WCAG 2.2 レベル AA)

スライドの内容(`products/<name>/content/`)で左右される達成基準を対象にする。

| ID | 達成基準 | 区分 | 判定方法 | スライドでの合格条件 |
| --- | --- | --- | --- | --- |
| F-1.1.1 | 1.1.1 非テキストコンテンツ (A) | 必須 | 自動+目視 | 情報を持つ画像すべてに、画像が伝える内容(グラフなら結論と主要な値)を説明する alt がある。「画像」「図」などの無意味な alt は不可 |
| F-1.3.1 | 1.3.1 情報及び関係性 (A) | 必須 | 自動+目視 | 表は見出し行(th)を持つ。見た目だけの擬似的な表や見出しを使わない。リストは Markdown のリスト記法で書く |
| F-1.3.3 | 1.3.3 感覚的な特徴 (A) | 必須 | 目視 | 「右の図」「赤い部分」のように位置・色・形だけで指示しない |
| F-1.4.1 | 1.4.1 色の使用 (A) | 必須 | 目視 | グラフ・図で色だけで系列や状態を区別しない(凡例のラベル、直接ラベル、模様、形も併用する) |
| F-1.4.3 | 1.4.3 コントラスト(最低限) (AA) | 必須 | 自動+目視 | 文字と背景のコントラスト比 4.5:1 以上(24px 以上、または太字 18.66px 以上の大きな文字は 3:1 以上)。画像内の文字も対象。画像内の文字が「大きな文字」に当たるかは、実効サイズ(SVG の font-size × 表示倍率)で判定する |
| F-1.4.5 | 1.4.5 文字画像 (AA) | 必須 | 目視 | 文章を画像にしない。画像内の文字は図のラベル・軸・凡例など必要最小限にする |
| F-1.4.11 | 1.4.11 非テキストのコントラスト (AA) | 必須 | 目視 | グラフの棒・線・図形など意味を持つ要素は、隣接色・背景色とのコントラスト比 3:1 以上 |
| F-2.2.2 | 2.2.2 一時停止、停止、非表示 (A) | 必須 | 自動 | 自動で動く・点滅する・自動再生されるコンテンツを置かない |
| F-2.3.1 | 2.3.1 3回の閃光 (A) | 必須 | 自動+目視 | 1秒間に3回を超えて点滅するものがない |
| F-2.4.2 | 2.4.2 ページタイトル (A) | 必須 | 自動 | プレゼンテーションのタイトル(h1)が内容を表している |
| F-2.4.4 | 2.4.4 リンクの目的 (A) | 必須 | 自動+目視 | リンクテキストだけで行き先が分かる(「こちら」「ここ」は不可)。引用番号リンク(`[1]`)は、同じ注記の直前に資料名がある |
| F-2.4.6 | 2.4.6 見出し及びラベル (AA) | 必須 | 自動+目視 | 全スライドに `##` 見出しがあり、そのスライドの内容を表している(目次として読んで話の流れが分かる) |
| F-3.1.1 | 3.1.1 ページの言語 (A) | 必須 | 自動 | `<html lang>` が本文の言語と一致する(既定は `ja`) |
| F-3.1.2 | 3.1.2 一部分の言語 (AA) | 推奨 | 目視 | 長い外国語の引用がある場合は言語を明示する(Markdown では困難なため推奨扱い) |

### テンプレートで担保している基準

以下は 共通テンプレート(`build.js` / `src/`)側で満たしている。**`src/` や `build.js` を変更したランでは
必須として再検証する**。変更していなければ「テンプレート担保」と記載すればよい。

- 2.1.1 キーボード / 2.1.2 キーボードトラップなし(`src/deck.js` の矢印キー・PageUp/Down 操作。
  引用番号リンクは Tab で移動し Enter で参考文献スライドへ移動、ブラウザの「戻る」で元のスライドに戻る)
- 1.4.4 テキストのサイズ変更 / 1.4.10 リフロー(`clamp()` と vw ベースのフォントサイズ)
- 2.4.11 フォーカスの非隠蔽(最低限)/ 2.5.8 ターゲットのサイズ(最低限)
  (フォーカス可能な部品はリンクだけ。非表示のスライドは `display: none` のためフォーカスされない。
  引用番号リンクなど文中のリンクは 2.5.8 のインラインの例外に当たる。ボタンなどを追加したら再検証)
- `src/style.css` の配色のコントラスト(`npm run check` が自動検査する)

## B. 表現・品質

| ID | 基準 | 区分 | 判定方法 | 合格条件 |
| --- | --- | --- | --- | --- |
| F-BUILD | ビルド | 必須 | 自動 | `npm run build -- <name>` が成功し、`npm run check -- <name>` に BUILD の error がない(参照画像がすべて存在する) |
| F-DENSITY | 1スライドの情報量 | 必須 | 自動+目視 | `npm run pdf -- <name>` で「はみ出している」警告が出ない(1280×720 に収まる)。目安: 箇条書き 6 項目以内、本文 250 文字以内、表 7 行×5 列以内。超える場合は分割する。`npm run check -- <name>` の warning は目視で確認し、超過を許容するならその理由を記載する |
| F-ONEMSG | 1スライド1メッセージ | 必須 | 目視 | 各スライドの主張が1つに絞られ、見出しから主張が読み取れる |
| F-DATA | データの正確性 | 必須 | 目視 | スライド上の数値・事実が計画レポートの「必要なデータ」に記載された値・出典と一致する。出典のない数値がない。仮データは「仮データ」と明示されている |
| F-SOURCE | 出典の明記 | 必須 | 自動+目視 | 外部データを使ったスライドには、短い資料名と引用番号リンクの出典がある。デッキ末尾の参考文献スライドに、引用番号の順で資料名・URL・取得年月が書かれ、引用番号・リストの番号・リンク先がすべて対応している(`slide-authoring.md`「出典と参考文献」)。`npm run check -- <name>` に F-SOURCE の error がない |
| F-TEXT | 文章の品質 | 必須 | 目視 | 誤字脱字がない。用語・表記(全角/半角、です・ます/である)がデッキ内で統一されている |
| F-LEGIBLE | 図内文字の判読性 | 必須 | 自動+目視(実測) | 1280×720 の表示で、画像内の文字の実効サイズ(SVG の font-size × 表示倍率)がすべて 16px 以上。表示倍率は `slide-authoring.md`「画像」の式、または実測した表示サイズで求める |
| F-CHART | グラフの正しさ | 必須 | 目視 | 軸ラベル・単位・凡例がある。縦軸を0から始めない場合はその旨を示す。データの見せ方が誤解を招かない |
| F-EMOJI | 絵文字 | 必須 | 自動+目視 | 絵文字は `slide-authoring.md`「絵文字」の一覧にあるものだけを、一覧の意味で使う。どの絵文字にも同じ項目に意味の分かる文字が併記されている。見出し・タイトル・SVG の図の中に絵文字がない。絵文字を使わないデッキは合格。`npm run check -- <name>` に F-EMOJI の error がない |
| F-IMAGE | 画像の品質 | 推奨 | 目視 | 画像は SVG を優先する。ラスター画像は表示サイズに対して十分な解像度がある。不要になった画像が `products/<name>/content/images/` に残っていない |
